# Универсальное приложение для сортировки и поиска

Проект для загрузки, обработки и сортировки данных с поддержкой различных стратегий и форматов данных.

## Структура проекта

### `/src/main/java/ru/aston/finalproject/`
Исходный код приложения:
* **`/appender/`**  
  Запись результатов в файл
    * `FileAppender.java` — Утилита для записи данных в файл в режиме добавления.
* **`/binarysearch/`**  
  Реализация пользовательского интерфейса для поиска
    * `SearchUI.java` — Пользовательский интерфейс для выполнения различных типов поиска по коллекциям с выводом результатов.
* **`/entity/`**  
  Сущности предметной области с реализованным компаратором и валидацией данных
    * `Cat` - класс кота с Builder паттерном
    * `Person` - класс человека с Builder паттерном
* **`/interfaces/`**  
  Интерфейсы для взаимодействия с внешними системами
    * `DataLoader.java` — Интерфейс для загрузки данных любого типа.
    * `SearchResultListener.java` — Интерфейс для передачи результатов поиска в обработчик данных.
    * `SearchStrategy.java` — Интерфейс для стратегий поиска элементов в списке.
    * `SortingStrategy.java` — Интерфейс для многопоточных стратегий сортировки с компаратором.
    * `Validator.java` — Интерфейс для валидации объектов.
* **`/loaders/`**  
  Загрузчики данных из различных источников
    * `FileCatDataLoader.java` — Загружает данные о котах из файла.
    * `FilePersonDataLoader.java` — Загружает данные о людях из файла.
    * `ManualCatDataLoader.java` — Позволяет вручную ввести данные о котах.
    * `ManualPersonDataLoader.java` — Позволяет вручную ввести данные о людях.
    * `RandomCatDataLoader.java` — Генерирует случайные данные о котах.
    * `RandomPersonDataLoader.java` — Генерирует случайные данные о людях.
* **`/managers/`**  
  Менеджеры для управления логикой
    * `DataLoaderManager.java` — Управляет загрузчиками данных для котов и людей.
    * `MenuManager.java` — Управляет меню и пользовательским вводом.
    * `SearchManager.java` — Выполняет бинарный поиск и многопоточный поиск элементов.
    * `SortingManager.java` — Управляет выбором стратегии сортировки и выполняет её.
* **`/processing/`**  
  Классы для обработки данных (фильтрация, валидация)
    * `SortingProcessor.java` — Обрабатывает загрузку, сортировку и поиск данных.
* **`/strategies/`**  
  Паттерн "Стратегия" для алгоритмов сортировки/поиска
    * `BinarySearchStrategy.java` — Реализация бинарного поиска с использованием компаратора.
    * `BaseSortingStrategy.java` — Базовая стратегия сортировки слиянием с многопоточностью.
    * `EvenNumberSortingStrategy.java` — Стратегия сортировки только чётных чисел с сохранением позиций нечётных.
* **`SortingApplication.java`**  
  Главный класс приложения, запускающий меню и управляющий процессом сортировки.

### `/src/test/java/ru/aston/finalproject/`
Тесты проекта.

### Ресурсы
- **`/src/main/resources/`**  
  Конфигурационные файлы, шаблоны, статические данные

### Системные файлы
- **`pom.xml`**  
  Конфигурация Maven для сборки проекта

## Быстрый старт

1. **Сборка проекта**:
   ```bash
    mvn clean compile

2. **Запуск тестов**:
   ```bash
    mvn test

3. **Запуск приложения**:
   ```bash
    mvn exec:java -Dexec.mainClass="ru.aston.finalproject.SortingApplication"


* Запустите SortingApplication
* Выберите тип сущности (коты/люди)
* Загрузите данные
* Выберите критерий сортировки
* (Опционально) Выполните поиск по нужным параметрам
